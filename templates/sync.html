How the Reliable Save Flow Works:

  1. When a student or academic record is saved, the Flask backend validates and commits immediately to the SQL database.
  2. An asynchronous record is automatically registered into the durable sync_outbox table.
  3. The user experiences instant response times without waiting for Google Apps Script network roundtrips.
  4. The Google Apps Script webhook receives updates and performs idempotent upserts based on table primary keys.

Google Sheets Setup Guide

To connect your Google Sheet to this system in under 2 minutes:

  1. Open your Google Spreadsheet (or create a blank one).
  2. In the menu, click Extensions → Apps Script.
  3. Paste the contents of google_apps_script.js (included in this repository) into the editor.
  4. Click Deploy → New deployment → Web app.
  5. Set Execute as: "Me" and Who has access: "Anyone".
  6. Copy the generated Web App URL and add it to your environment variables as GOOGLE_SHEETS_WEBHOOK_URL.
